# formats/ — codecs between bytes and `model::Project`

- Owns the native project (`O3PJ`) and settings (`O3ST`) codecs, OG import/export, MOD/S3M/MED importers (`med/`, `mod/`), WAV/AIFF/IFF sample readers (`wav/`, `iff_sample.*`), wavetables. Must not: do file I/O, allocate, block, or trust input. Readers/writers are resumable (`begin` / `step(budget)` / `report` over a `ByteSource` / `ByteSink`, run as jobs by `app/`); any input ends in `Done` or a typed `FormatError`. OG files keep their format exactly. May include `core` and `model` only.
- Entry points:
  - `include/o3os/formats/format.h`: `FormatReader` / `FormatWriter`, `FormatRegistry`, `FormatError`, `FormatReport`
  - `include/o3os/formats/builtin.h`, `src/builtin_formats.cpp`: `register_builtin_formats` (order matters for sniffing)
  - `include/o3os/formats/native.h`, `src/native_{reader,writer}.cpp`, `src/native_codec.h`: chunked big-endian native project
  - `include/o3os/formats/settings.h`, `src/settings_*.cpp`; `include/o3os/formats/og.h`, `src/og_*.cpp`
  - `include/o3os/formats/preset.h`, `src/preset_file.cpp`: the module preset file `O3MP` (OS-MODPRESET), read and written whole through a 1 KiB buffer; Python mirror `tools/o3preset.py` (ctest `preset_python`)
- Add a reader/writer: implement the strategy in `format.h`, register it in `builtin_formats.cpp`, add a test with a round trip (or an oracle for importers) and hostile input (truncated, oversize, bad values). Name the test so it matches an `o3os_unit_formats` pattern in `tests/CMakeLists.txt` (else it lands in `unit_rest`).
- Persistent formats (`.o3pj`, `.o3st`, any new file): a chunk's u16 version is major<<8 | minor. A change needs a version bump, a loader that still reads every older version, and a round-trip test. A newer major is refused; a newer minor reads the known fields and sets `unverified_version`. Unknown chunks are carried. Update `docs/formats/*.md` and the Python mirror `tools/o3project.py` (ctest `project_python`).
- Tests: `tests/{native_format,native_fuzz,og_*,med_*,modimp_*,wav*,settings_format,preset_format,format_registry}_test.cpp`. Scoped: `ctest --test-dir build-os-host -R 'unit_formats|unit_fuzz|project_python' --output-on-failure` (or `-L formats`); `O3OS_CI_SCOPE=changed tools/ci.sh host` maps `formats/` to labels `formats fuzz app`. `med_openmpt` / `modimp_openmpt` need libopenmpt (a local run skips without it; `O3_CI=1` makes it a failure).
- Docs: `docs/formats/{o3-project,o3-settings,o3-preset,og,med,mod}.md`, ADR 0004, 0006 (OG compatibility), 0007. Hardware: `platform/mk66/tools/hil/{persistence,qa_file_import}.json`.
