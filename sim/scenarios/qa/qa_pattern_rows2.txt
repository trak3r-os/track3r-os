# OS-QA: twelve rows of docs/qa/catalogue/pattern.md proven with asserts only (no `snap`, so this scenario needs no golden), the way qa_sample_load_rows.txt does it: QA-PAT-216, 219, 220, 226, 227,
# 228, 229, 246, 247, 311, 312 and 320. Every block opens a fresh demo document (`document`), but the app keeps its view across it (screen, mode, cursor, the pattern clipboard), so each block first puts WATCH and the cursor back at the start; the clipboard is untouched until the second block, the first to copy. The demo's pattern 1 (app::fill_demo) is 12 tracks of 64 steps and the asserts read what it holds: track 0 (KICK)
# note 25 on instrument 1 every 4th row from row 0, track 1 (SNARE) note 27 on instrument 2 on rows 4, 12 ..., track 3 (ACID) a note on every row on instrument 4 (13, 13, 25, 16 repeating) with an FX1 on
# every 4th row from row 3, track 4 (BASS) note 13 on instrument 5 on row 0, track 10 (LINE L) volume 64 and an FX but no note on row 0. The state line's keys used below: mode= (0 STEP, 3 WATCH), pattern=, track=,
# row=, col=, overlay=, msg= (the last strip text, spaces as _); the model's pat.<p>.<track>.<row>.<field> (both 0-based) and digest.

# QA-PAT-229 (OS-DELPULL): Insert then Shift + Delete is the identity. Demo track 0 has notes (25) on rows 4 and 8; the cursor is on row 3 and goes down to row 4 by the JUMP (1) with the pull (OS-DELJUMP).
