# OS-FINALQA (docs/specs/OS-FINALQA.md): the Record screen's QA rows, docs/qa/catalogue/record.md. One `snap qa_rec_NNN` per row with a visible result; the goldens are keyed qa_record/qa_rec_NNN.
# OS-SHIFTROW: with Shift held the key row shows the Shift layer: a label only on a key that does something, "-" elsewhere; Shift + F never falls through to the plain key.

# QA-REC-001: the Record screen with Shift held on SOURCES: all eight keys "-" (CH-10 / CH+10 are the RADIO page's, qa_rec_001_radio below).
tap samplerec
press shift
snap qa_rec_001
release shift

# QA-REC-012 (OS-CFG-ARROWS): the screen button turns the page (the arrows edit the row, QA-REC-060). On SOURCES, the button twice is RADIO (the tab underlines RADIO); once more wraps back (the page is shown in qa_rec_012).
tap samplerec 2
snap qa_rec_012
