# OS-SHIFTROW: with Shift held the key row shows the Shift layer: a label only on a key that does something, "-" elsewhere; Shift + F never falls through to the plain key.

# FQA-1a: the point, ZC and CHOP keys need a real sample. The card e2e_og (a generated fixture): File > OPEN loads one OG project whose instrument 1 is a loop of 200 frames, mode LOOP FWD. The waveform lane
# stays empty in the simulator; the rows (START, LOOP START, LOOP END, END), the ZC state in the header and the slice list are the visible results.
card e2e_og
tap file
wait 300
tap f1
wait 800
tap sampleplay
wait 3000
