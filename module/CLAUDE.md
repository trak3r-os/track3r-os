# module/ — `.tmod` host: loader, image checks, views; `sdk/` is the MIT module ABI

- Owns the module file format checks (`image`), the stepped SD loader, bump arenas (no heap, reset on project change), the restricted draw API with record-then-replay views, and the table of built-in modules. Must not: trust a file (every refusal is tested), link `platform` (the composition root wires the hooks), or include more than `core`, `usb`, `hal`. `sdk/` is MIT (`sdk/LICENSE`) and must stay free of OS headers.
- Entry points:
  - `sdk/o3module.h`: the C ABI (descriptor, `o3m_host` services, draw API, file header); the ABI version history is in its header comment
  - `include/o3os/module/image.h`, `src/image.cpp`: what a `.tmod` may say; `loader.h`: stepped load; `arena.h`; `view.h`: views; `builtin.h`: modules in the image
  - `sdk/README.md`: what is verified and what is not; `docs/guides/{module-sdk,app-modules}.md`
- ABI changes are additive: a new field/flag/host function goes at the end and bumps `O3M_ABI_MINOR`; anything else is a major bump. Capability bits and published values are frozen, never renumbered. Every older-minor module must still load unchanged. The descriptor is sized per declared minor (`O3M_MODULE_SIZE(minor)`: 64 bytes up to 1.7, 80 from 1.8, 84 from 1.11, 100 from 1.12; `Desc32` is the 64, `DescExt32` the 1.8 tail, `DescImp32` the 1.11 one, `DescFx32` the 1.12 one): write a descriptor's `struct_size` with the macro, never `sizeof(o3m_module)`, and read the members past byte 64 only for a module that declares 1.8. Extend the layout test `module_image_test.cpp` ("the SDK's layout is what the format says"), `module_loader_test.cpp`, `module_host_api_test.cpp`; add the entry to the ABI list in `o3module.h`. It is a published ABI: Level C.
- New module: skills `sd-module` and `tmod-perf`; manifest `module.json` -> header with `tools/o3m_gen.py`, packed by `tools/o3m_pack.py`; code under `modules/<name>/`, starting points in `modules/templates/{instrument,effect,effect_stereo,effect_key,app}/` (`o3m_gen.py new --kind ...`). Effects (kind 2) run as per-track inserts and as the master insert (OS-INSFX, `audio/insert_host.h`; the master one is two instances, L and R, counting 2 of the 4); the first sample effect is `modules/effects/biquad/` (the pattern to copy: manifest, one source, a host test against a double-precision reference). ABI 1.12 (OS-INSFX-ABI2: stereo, the clock, a sidechain key, factory presets; SDK README section 3b): the manifest keys `"stereo": "widens" | "capable"`, `"presets"` and a `"type": "key"` parameter, the templates `effect_stereo` (a WIDENS auto-pan) and `effect_key` (a sidechain ducker); the OS acts on them slice by slice (A3 to A9), so a 1.12 module builds and loads before it sounds. ABI 1.13 (OS-MODRATE S2, `docs/specs/OS-MODRATE.md`): one more bit of `fx_flags`, `O3M_FX_RATE` (2), an instrument's (a per-kind, per-minor rule in `image.h` `fx_flags_allowed`, mirrored by `o3m_pack.py` and `DescFx32`); the manifest key `"rate": true` needs `"abi": "1.13"`; Sine, FM, TB-303, SID and Chip carry it (Chip since S5: `chip_ce.h` clamps the step at 0.45 of the rate, `kLfsrMax` 8, the filter ceiling at 0.45 of the rate).
- Tests: `tests/module_*_test.cpp` (they fall in `unit_rest`), `tests/app_grammar_test.cpp` (the eleven shipped apps through the whole stack in the simulator, with `tests/support/app_grammar.h`: group `unit_apps`) and ctest `o3m_*`. The apps' shared source (the one grammar, `draw_rows`, `own_set`) is `modules/apps/common/o3m_edit.h`. Scoped: `build-os-host/tests/o3os_tests --source-file='*/module_*_test.cpp'` plus `ctest --test-dir build-os-host -R 'o3m_' --output-on-failure` (`qemu_module_*` run under `tools/ci.sh qemu`). `module/` is unmapped in `tools/ci.sh`'s scope map, so `O3OS_CI_SCOPE=changed` runs everything.
- Host tests do not prove a module works on the Tracker; name the open hardware check (`sdk/README.md` section 10).
- Docs: ADR 0002, ADR 0014 (app host API). QA rows in `docs/qa/catalogue/modules.md` (format in `app/CLAUDE.md`); hardware steps `platform/mk66/tools/hil/{modules,qa_modules}.json`.
