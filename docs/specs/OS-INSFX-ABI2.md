## 1. Goal

Give effect modules the four things the next effect packs need, as one additive ABI minor that every module of 1.0 to 1.11 still loads under: (1) **stereo**: an effect declares a stereo shape; on a track it takes the mono block M (and the side S a stereo voice or an earlier stereo insert brings) and writes M plus a side S into the lane stereo voices already use (`Graph::side_pass`), so a mono source can come out wide and a stereo voice keeps its S; on the master one stereo instance replaces the dual mono pair; (2) **the clock**: the tempo in force and the beat position, for synced delays and LFOs (instruments get it too); (3) **an audio sidechain key**: an effect reads another track's level every block, at most one block (1.45 ms) late; the key track is a module parameter, so it is stored in the `INSX` blob with no project format change; (4) **factory presets**: the descriptor lists named parameter sets; the OS applies one through `set_param` and writes the blob.

## 3. Design

### 3.1 The ABI surface (1.12)

`O3M_ABI_MINOR` 11 -> 12. Four members appended to the descriptor **after `importer`** (`struct_size` 100 for a 1.12 module, `O3M_MODULE_SIZE(12)` = `sizeof(o3m_module)`; the macro's 1.11 branch becomes `offsetof(o3m_module, render_st)` = 84; read only when the module declares 1.12). An effect's `importer` is NULL (F4), so a generated entry fills it positionally. A kind 3 module may declare 1.12 with the four members zero; the tracker importer stays at 1.11.

| Offset | Member | Meaning |
|---|---|---|
| 84 | `uint32_t (*render_st)(void* state, const float* in_l, const float* in_r, float* out_l, float* out_r, uint32_t frames)` | NULL: a mono effect. Non-NULL (effects only): the stereo render; `in_*` and `out_*` may be the same buffers; return value as `render` (1 while it may sound, 0 when silent and idle); frames 1..64 |
| 88 | `uint32_t fx_flags` | `O3M_FX_WIDENS` (1): the effect makes a stereo image from a mono input; the OS calls `render_st` on every block. Without it, a module with `render_st` is **stereo-capable**: `render_st` on a block whose input has S, `render` otherwise, one state for both (the module makes the switch click-free). Other bits 0. WIDENS needs `render_st` |
| 92 | `const o3m_preset* presets` | the factory presets, NULL when none |
| 96 | `uint32_t preset_count` | 0..`O3M_PRESETS_MAX` (32), zero exactly when `presets` is NULL |

`o3m_preset { const char* name; const float* values; uint32_t count; }` (12 bytes): `name` 1..15 printable ASCII (`O3M_PRESET_NAME_MAX` 16), `values[count]` in parameter order, `count` 1..`param_count`, each finite and within its parameter's range; **a preset sets every parameter**: those past `count` take their default. Instruments and effects only (Q8 a); a kind with no parameters has none.

A parameter flag `O3M_PARAM_KEY` (32): an INT parameter, min 0, max 16, `labels` entry NULL: 0 = no key, 1..16 = the key track. Effects only, at most two a module; not learnable (the OS treats it as `NO_LEARN`); the OS shows it as `OFF`, `T1`..`T16`. A module of 1.11 or below never has it honoured. Bit 32 is free (the flags use 1, 2, 4, 8, 16 and the unit byte 8..15).

Two members appended to `o3m_host` (size 52 -> 60), for every kind but the importer, whose own table stays 52 bytes (A-12):

- 52: `int32_t (*get_clock)(o3m_clock* out)` — `o3m_clock { uint32_t size; uint32_t flags; uint32_t tempo_x100; float beat; }` (16 bytes, `out->size` set by the caller as in `get_transport`). `flags`: `O3M_CLOCK_PLAYING` 1, `O3M_CLOCK_STARTED` 2 (a run started in this block), `O3M_CLOCK_WRAPPED` 4 (the beat went back: a new pattern or a jump). `tempo_x100`: what plays (half and double time included); the project tempo while stopped. `beat`: the playhead at this block's first sample, in beats (4 steps) from step 0 of the pattern that plays, the fraction inside a microstep interpolated (piecewise linear under swing); 0 while stopped. Values are those of the current block; returns 0, or 1 when the OS has no sequencer.
- 56: `float (*track_level)(uint32_t track)` — track 0..15: the linear peak (0..1) of that track's mono block after its inserts, before the fader (Q3 a), of this block when that track's strip already ran in it, else of the previous block; 0 for a silent track, a bad index, or a track no bound insert's KEY parameter names. Render context.

Compatibility: every module of 1.0 to 1.11 loads and runs bit for bit as before (its descriptor is 64, 80 or 84 bytes; the new members are never read; the host table only grew). An OS of 1.11 refuses a 1.12 module (`NEEDS NEWER OS`, the minor rule): a project whose insert names one still opens there and plays it dry (the OS-INSFX S3b skip rule; the `INSX` record and the blob are kept). A module that can live without the clock or the key may declare a lower minor and test `O3M_HOST_HAS`; one that needs them, or has `render_st`, presets or a KEY parameter, declares 1.12. `O3M_ABI_ASSERT` lines: `module_1_11` becomes `importer 80 && render_st 84` (its `sizeof == 84` would fail), new `module_1_12` (render_st 84, fx_flags 88, presets 92, preset_count 96, size 100), `host_1_12` (get_clock 52, track_level 56, size 60), `preset_pod` (12), `clock_pod` (16).

### 3.2 Stereo on a track (the stereo adapter)

`InsertHost::run` keeps the `InsertFn` signature; the instance knows its shape. For a stereo instance (WIDENS, or stereo-capable on a block whose input has S):

1. **Input S.** `Graph::side(track)` (the voice's S, or an earlier stereo insert's), scaled by `(255 - wet) / 255` of an un-bypassed mono insert before it in the same strip (ramped over the block from `wet0` to `wet1`: a steady mono insert gives 0, so D6 holds). Null or a zero gain: no S (a stereo-capable effect then runs `render`, the mono path, unchanged).
2. **In:** one loop: `L = (M + S) / 32768`, `R = (M - S) / 32768` into the Graph's two scratch planes (exact: a 17-bit integer times 2^-15).
3. `render_st(state, L, R, L, R, n)` between the platform's enter / leave stamps.
4. **Transition ramp** (bind, bypass, forced bypass, clear): the dry pair is recomputed from `io` and the input S (both still intact), blended per sample; no extra plane.
5. **Out:** one loop: `M' = (L + R) / 2`, `S' = (L - R) / 2`, each to Q15 by the module rule (NaN 0, saturation counted) into `io` and the host's one **shared S block** (64 x int16, SRAM_U). Shared is safe: `side_pass` consumes a track's S before the next track's inserts run (F5); a second stereo insert on the same track reads it as its input and overwrites it after converting.
6. `Graph::feed_side(track, s_block)`, so the strip's `side_pass` adds S' to MAIN.
7. **`side_pass` rule** (flash): walking the slots in order, a stereo insert resets the S gain to unity (S is its output), a mono one multiplies it by `255 - wet` as today. The stereo bit lives in a new `Graph` mask (`st_ins_`, one bit per slot, written by the render at a block boundary; `Strip` and `Insert` do not grow).
8. **No stale S:** `InsertHost::begin_block` (flash, after the block) sets to null every `side_[t]` that holds the host's S block; `feed_sides` keeps writing the voices' S as today. `play_block` is untouched (SRAM_L +0 B).

Idle skip: the input is silent when M and S are. Tail (S2): the zero-output count needs M' and S' both zero. Outputs other than MAIN stay mono: the sends, CUE, REC and the USB track stems carry M' (OS-STEREO decision 4, F10). Cost [est, F9]: about 4.5k to 5.5k cycles a block for the adapter and the S pass (1.7 to 2.1 %) before the effect's own render; Q7 sets the gate. `diag bench insert` gains `insert_st` (the stereo adapter around an identity) and `insert_st_effect`.

**Known limitation (A4 review, recorded in the tests):** a stereo-capable effect that is stereo only through its S tail drops to the mono render in the same block when M is live again while S is null, and the ringing S tail is cut in one block, not ramped (`InsertHost::run`: the tail clause of the stereo test needs a silent M).

**The cap (Q4 a).** `InsertHost::begin_block` counts the WIDENS track inserts that run (phases In, On and the two ramps out; not Bypassed or Off) and calls `VoicePool::set_st_reserved(n)` when it changes (flash): `st_start` then sees `kStMax - n` side blocks; voices that hold a block keep it to the end of their note. The count is of inserts, not tracks: two WIDENS inserts on one track reserve two blocks. **One-block lag:** the count runs at the block boundary, so a note that starts in the block after an Activate can still take the last free block — and once it has, it keeps it to the end of the note (nothing is taken from a sounding voice; the reservation only refuses new ones). The INSERTS cell and the picker line show `ST` for a stereo effect; `ins` lists the reservation.

### 3.3 Stereo on the master (after OS-INSFX S6)

A stereo effect (either shape) on the master is **one** instance: `render_st(l, r, l, r, n)` in place on the float planes, the S6 scrub of NaN and infinity after it, counting 1 of the insert cap; a mono effect stays dual mono (2 instances, S6). No reservation (the master adds no S path). OS-INSFX D4 becomes "dual mono for a mono effect, one stereo instance for a stereo one".

**A7 as built (2026-11-07).** `InsertHost::instances_for(where, mod)` is the module-aware count: the master's is 1 when `shape_of(mod)` is not Mono, else the S6 `states_for` (2). `bind(kMasterWhere, stereo)` takes ONE record and ONE state block (`mate` kNone, `state_r` ignored); the render's `run_master` sees `mate == kNone` and runs `run_master_st`: `render_st(state, left, right, left, right, n)` in place on the chain's two float planes, `scrub_plane` on both after it (`Stats::scrubbed` counts them), the idle skip on both planes silent. Steady, render_st runs IN PLACE (`l, r, l, r, n`: no copy, identity bit for bit); in a TRANSITION block only (bind, bypass on/off, unbind, a net's forced bypass) it renders into the graph's two chain-wet planes (`Graph::chain_wet(0)/chain_wet(1)`: the CUE bus's accumulators `acc_cue_`, which `finish_bus` has consumed and ZEROED in `run_buses` before the chain runs — no SRAM cost; a first attempt with a new static 64-float buffer failed the mk66 link, SRAM_U was at the 32 KiB-free budget) and the dry planes and the wet are blended per sample over the block, the same one-block linear ramp the dual-mono pair runs: no edge steps (the Level C review fold). Both chain-wet planes are zeroed again right after the blend (128 int32 stores, transition blocks only): `acc_cue_` must be zero between blocks because the next block accumulates into it — without that, the next block's CUE output is the float bit patterns as full-scale noise (the Level C recheck BLOCKER, fixed and tested: the CUE jack over a transition equals the run without the insert, and stays silent with CUE silent). The pair's machinery is mate-guarded throughout (`apply`'s Activate admits a lone master record only when the module is stereo, `set_param`/`apply_param`/`cost`/`account`/`finish_leave`/`prepare_export` treat it as one, at 1x the nets' cost). The cap checks know the shape: `ModuleUi::project_instances` counts a master record 1 when its loaded module is stereo, the assign checks room with `instances_for` (early when the module is already loaded, exactly after the load), the binder takes one state block, and the picker's open refuses only when even one instance does not fit (the pick itself says `INSERTS FULL` for a mono module beside three taken). Tests: `audio_insert_test.cpp` `master stereo:` (identity bit for bit L and R with `render_st` called and one record; a NaN/infinity from `render_st` never reaches the limiter, finite samples exact; one instance counts 1 of the cap beside three tracks while a mono master still gets `NoInstance`), `mixer_inserts_test.cpp` (the ST cell with three tracks plus the stereo master filling the cap, a fourth `INSERTS FULL`; the master's picker opens beside three taken, a mono pick refused). All three audio cases fail before the fix (the pair binds, no `render_st`, no scrub); the fold adds the ramp test (a block straddling bind and one straddling bypass: no sample moves more than the ramp step) and the one-instance lifecycle test (set_param / a ring ParamChange reach the single record — the `wh_[where+1] == kNone` guard in `set_param` — bypass, forced bypass, reset, export equal bits, unbind), plus a binder case (a stereo master from a full project binds one instance beside three track inserts). QA-MIX-104 added, QA-MIX-068/085 reworded; `qa_ins_006` re-taken (the picker open beside three taken). Sizes (mk66 release, against the pre-A7 tree 515b541d): `.text` 971,212 -> 971,676 B (**+464 B**), `.ramfunc_l` 26,904 -> 26,904 B (0), SRAM_L 49,176 -> 49,176 B (**0**), SRAM_U 139,064 -> 139,064 B with the fold (the chain-wet planes reuse the CUE accumulators) — the spec's +0.4 KB / SRAM 0 holds. Unit check stays for the tester: the template on the master, `diag cpu` delta, the limiter still catches peaks, 0 underruns.

### 3.4 The clock

`EventSource` gains `ClockFn` (the sequencer's `clock_at(sample)`: flags and the beat as Q16.16, from `step_start_`, the step length and the microstep, in flash). `Engine::block_end` (flash) writes a `module::ClockState` (16 bytes, SRAM_U) for the next block: `tempo_x100`, beat, flags; `render_offline` writes it at the start of each export block. `get_clock` reads it. Instruments get it too (OS-SNDMOD's "a synced LFO needs an ABI minor").

### 3.5 The sidechain key

- **Which tracks are keys.** At bind (the blob) and on every `ParamChange{Insert}` to a KEY parameter, the host records the instance's key tracks; `begin_block` folds them into `key_mask` (16 bits), published for the console.
- **Measuring (Q3 a).** For a keyed track, insert slot B measures: an empty slot B gets the host's **key tap** (a flash `InsertFn` that writes the block's peak and changes nothing); a module in slot B measures its own output in `run`. When a module leaves slot B of a keyed track the tap goes back; when the track stops being a key the tap is cleared. The tap is not an instance (no cap, no governor; about 0.15k cycles a block, in `base`).
- **The word.** `key_[t] = (block & 0xFFFF) << 16 | peak` (peak 0..32768, one store); `track_level(t)` takes it when its block stamp is this block or the previous one, else 0. Strips run in track order, so a key on a lower track is this block's, on a higher one (or the same) the previous block's: at most one block late; the master insert always reads this block's.
- **Ghost keys.** `Engine::block_end` adds `key_mask` to the tracks the voice gate may not act on (`gate_off_`, flash), so a muted key track's voices still render and its tap still measures; documented CPU cost.
- **Export.** `prepare_export` clears the key words, so two exports give the same bits.
- **Persistence.** The key is the parameter's value in the `INSX` blob: no format change. A project whose key names a track that makes no audio reads 0.

### 3.6 Factory presets

`app::ParamSet` (`app/include/o3os/app/param_set.h`, pure: a name, a source Factory or Card, a 32-bit mask of the values given, 32 floats in the module's order) is the one parameter-set model; OS-MODPRESET reuses it. `ModuleUi::factory_presets(target, out[])` builds them from the descriptor; `ModuleUi::apply_preset(target, set)` writes every parameter (a masked value clamped to the descriptor and rounded for INT, else the default): on an **instrument** through `write_module_param` inside one `begin_group` / `end_group` (one undo unit); on an **insert** into the `INSX` blob through `Editor::set_insert` and `InsertHost::set_param` for each (no undo, OS-INSFX D9). At most 32 ParamChanges: one block's drain (F14). The UI (Q6 a): **F5 PRESET** on a module's parameter page (instrument or insert) opens a list overlay (Up / Down / encoder, F1 LOAD, F8 BACK) with the factory presets; a module with none says `NO PRESETS`. Toast `PRESET <NAME> LOADED`.

## 5. Real-time rules

`run`, `begin_block`, the key tap, `apply_param`, `get_clock`, `track_level`: no allocation, no I/O, no blocking, no double, bounded loops (16 tracks, 4 instances, 2 slots). New render state in SRAM_U, code in flash (`O3OS_AUDIO_COLD`); `play_block` and `run_tracks` are not edited. Single writers: the render writes the Graph's slots and masks, `side_[t]` (with `feed_sides`, same context, in order), the key words and the clock store; the main loop writes only the command ring and ParamChanges, as OS-INSFX section 3.

## 6. Assumptions (decided here; local, testable, reversible)

- A-1 One minor, 1.12, for all four features; A1 publishes the whole header shape, the later slices wire it; the minor is frozen only at a release (1.11 and 1.12 may ship in the same one; neither layout changes).
- A-2 A stereo effect keeps a mono `render` (the loader's rule for effects stays): used by a stereo-capable effect on mono blocks; a WIDENS effect's `render` is called by no host of this OS but must be valid.
- A-3 S stays MAIN only, as for stereo voices; sends, CUE, REC and USB track stems carry M'.
- A-4 One shared S block for every stereo track insert (F5 ordering); the stereo bit of a slot is a Graph mask, not a Strip field.
- A-5 The clock's beat counts from step 0 of the playing pattern (Q5); STARTED and WRAPPED flags; `tempo_x100` what plays; while stopped the project tempo and beat 0.
- A-6 The key is a block peak (0..32768), not RMS and not the key's audio; at most two KEY parameters a module; KEY is never learnable.
- A-7 The key is measured in slot B (the tap, or the module there); a key track's voices are exempt from the OS-ODD11 gate while it is a key.
- A-8 Factory presets: at most 32 a module, names up to 15 characters, a preset sets every parameter; applying is one undo unit on an instrument, none on an insert (D9).
- A-9 F5 is PRESET on a module target's parameter page (a module has at most 4 pages, F14); Shift + F5 is left for OS-MODPRESET's SAVE.
- A-10 Built-in modules (TB-303, Chip, FM, SID) get no factory presets in this item (flash); OS-MODPRESET decides how they get presets.
- A-11 At 1.12 an app and an importer descriptor carry the four new members zero / NULL, and `read_desc` and `add_native` refuse otherwise (presets for instruments and effects only, Q8 a); the tracker importer stays at 1.11.
- A-12 The OS has two host tables: `ModuleVoices::host_` is 60 bytes; the importer's (`ModuleImport::build_host`) keeps `size` at 52 (`offsetof(o3m_host, get_clock)`), so `O3M_HOST_HAS` is false there for the clock and the key level and no importer sees a NULL function.

## 7. Risks

- R1 **CPU of a stereo track insert** (Q7): the adapter is about twice the mono one; measured in A4 before merge; a fused SRAM_L kernel is the fallback only if SRAM_L room appears.

- R6 **ABI mistakes are permanent** once a release ships 1.12: Level C risk review of A1 plus one independent review; the layout asserts.
- R7 **SRAM_U margin** (1,808 B at dev 5de6fed4): about +232 B here; checked per slice with `size -A`; re-read before A3, since other items have taken 160 B since 68df8566.
- R8 **Module switching shape** (stereo-capable, S appears mid-note): the module's job, the SDK says so; the key template shows the pattern.
