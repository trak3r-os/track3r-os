# track3r-os v1.1.0: release notes

v1.1.0 adds a SID-style instrument, stereo samples, USB outputs of up to 10 channels, new Song pages and tools, and many fixes, among them issue #2. The full list is in the [changelog](../CHANGELOG.md); the earlier notes are [v1.0.1.md](v1.0.1.md) and [v1.0.0.md](v1.0.0.md).

track3r-os is community firmware for the Polyend Tracker. It is unofficial and not affiliated with Polyend. Installing it replaces the firmware in your unit. It is licensed GPL-3.0-or-later. Third-party licences are in [THIRD_PARTY.md](../../THIRD_PARTY.md).

**Back up your SD card and keep the official firmware file before you install.**

## Read this first: going back

v1.1.0 images are padded to a whole 4 KiB flash sector: the SD bootloader leaves a short last sector as it was, so an image that does not end on a sector may crash at boot. v1.0.1 and v1.0.0 are such images. **To go back to them through the Update screen** (Config, INFO, `F8`), pick the file: the screen says NOT PADDED. TRACK3R-OS WILL PAD A COPY OF IT? Press `F1` (**PAD**). The unit writes `pad-<name>.ptf` next to the file, checks it, and then offers to install it as usual. Your file is not changed. From a computer, `o3console.py --pad` does the same. The hidden reset button, with the older file alone in `Firmware/`, works as before (see the [installing guide](../manual/install.md)). Whether the Update screen takes an official Polyend file has not been checked; use the reset button for the way back to the official firmware.

## What is new

- **SID-style instrument**, built in: saw, triangle, pulse with PWM, noise and combined waves, sync and ring, a stepped ADSR, and a filter with a 6581 or 8580 model switch.
- **Stereo samples**, opt-in per instrument (the STEREO row); up to four stereo voices at once.
- **USB audio outputs of 2, 4, 6, 8 or 10 channels**, chosen per project on Mixer, STEMS.
- **Song: STAGE and TIMELINE pages.** TIMELINE has a note map and an ENERGY row; STAGE is no longer in the Song key cycle.
- **Song: FORM and BRIDGE** in the TOOLS dialog.
- **Import** of module files by their header, and of 15-sample Soundtracker MODs.
- **Step effects 23, 24, 33 and 36** start their LFO.
- **Config and Record:** Left and Right edit the value under the cursor.
- **Update pads an older image after asking.** When a missing pad is the only fault, the Update screen offers to write a padded copy and install it; any other fault is still refused, and an existing copy is never replaced.
- **Cheaper reversed voices** (PLAYBACK, effect 26): six reversed voices cost +0.23 percentage points of the CPU on the unit, against +6.19.

A project that uses stereo samples is saved with a newer instrument version; any other project is saved as before. Projects saved by v1.0.1 open in v1.1.0.

## What is fixed

- **Overdrive and Bit depth now shape module instruments** (TB-303, FM, Chip; issue #2).
- **The update dialog reaches every file of `Firmware/`.** The old limit of 12 files is gone.
- **Update file names over 30 characters are refused** (`NAME TOO LONG: 30 MAX`).
- **A boot crash caused by the image's last flash sector.** Images are padded, and the Update screen pads an older one after asking.
- **Saving after a card remount** no longer points a project at a missing WAV.
- **The demo kit no longer overwrites a project's instruments.**
- **MOD import:** the loop start of 15-sample files, and a MOD with no room for a pattern is refused before the NEW question.
- **Labels and arms:** Chip's and SID's Wave views, Config's `APPLY?` mark, TIMELINE draws at most 12 tracks.

## Files

- `track3r-os-v1.1.0.ptf`, the update file (21 characters, within the 30 limit). For a first install from the official firmware you rename your copy on the card (see Install).
- `SHA256SUMS`, the checksum of the `.ptf`.

Check your download with `sha256sum -c SHA256SUMS`.

The app modules are the same as for v1.0.0: the release `apps-v1.0.0` on the Releases page. The module ABI did not change since v1.0.1 (only the SDK README text differs), so those `.tmod` files still work.

## Install or update

- **From track3r-os v1.0.1 or v1.0.0 (with working pads):** copy `track3r-os-v1.1.0.ptf` into `Firmware/` on the card, put the card in the unit, open Config, INFO and press `F8` (UPDATE). A padded image is what the unit needs; a v1.0.1 or v1.0.0 unit has no padding check.
- **From the official firmware, or when the pads are dead (v1.0.0 on a later unit):**
  1. Copy everything on the SD card to your computer.
  2. Copy `track3r-os-v1.1.0.ptf` into `Firmware/` and rename the copy to `PolyendTracker_0.0.1.ptf`. It must be the only `.ptf` there. Do not use the Polyend Tool app.
  3. Use the hidden reset button, as in Polyend's [emergency flashing page](https://polyend.ladesk.com/929798-How-do-I-perform-the-emergency-flashing-procedure).
  4. After the restart, open Config, INFO. BUILD ID should show `v1.1.0`.
- **Going back to v1.0.1 or v1.0.0:** on the Update screen, with **PAD** as in "Read this first", or by the reset button as in the second way above with the older file.

The full steps are in the [installing guide](../manual/install.md).

## Known issues

- Swapping the SD card can crash the unit. Switch the unit off before you change the card.
- Very heavy projects can exceed the CPU budget; some Perform effects cost CPU while held (the five LFO rows most). See the [CPU budget](../architecture/cpu-budget.md).
- A cancelled effect leaves the free sample memory lower until the next effect reuses the buffer.
- A project saved with no instrument at all can open at 120 BPM instead of its own tempo (seen on the unit, under investigation; a project with instruments keeps its tempo).
