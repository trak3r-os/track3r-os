# track3r-os v1.4.1: release notes

v1.4.1 fixes the on-device update: the Update screen (Config, INFO, `F8`) now installs any well-formed `.ptf`, the official Polyend firmware included. Everything else is v1.4.0; see its [release notes](v1.4.0.md) and the [changelog](../CHANGELOG.md).

track3r-os is community firmware for the Polyend Tracker. It is unofficial and not affiliated with Polyend. Installing it replaces the firmware in your unit. It is licensed GPL-3.0-or-later. Third-party licences are in [THIRD_PARTY.md](../../THIRD_PARTY.md).

**Back up your SD card and keep the official firmware file before you install.**

## Fixed

- **Install any firmware from the Update screen.** v1.4.0 refused every official `PolyendTracker_*.ptf` with "bad reset vector". The check now keeps only what protects the unit: a valid Intel HEX file that fits the flash, and the flash configuration field (a wrong value there could lock the chip for good). An official file is offered **PAD** first, because it is not padded to a 4 KiB sector; the padded copy then installs. The hidden reset button remains the way back from any image.

## Read this first

- **Modules.** Unzip the modules zip at the card root, as for v1.4.0: the TB-303, Chip, FM and SID instruments load from `modules/instruments/`, and MOD, S3M and MED import needs `modules/importers/tracker.tmod`. An update with the `.ptf` alone leaves import without its reader.
- **Saved files.** No change from v1.4.0. The module ABI is 1.13.

## Files

- `track3r-os-v1.4.1.ptf`, the update file.
- `track3r-os-v1.4.1-modules.zip`, every external module (TB-303, Chip, FM and SID among them), the MOD/S3M/MED importer, the factory presets and the `.ptfx` Sample Editor plugins. Unzip at the card root.
- `track3r-os-v1.4.1-examples.zip`, demo projects, a drum kit, wavetables, an OctaMED module and the licences of the files. Unzip at the card root.
- `SHA256SUMS`, the checksums of the files (the values are also in the table below).

Check your download with `sha256sum -c SHA256SUMS`.

## Install or update

- **From track3r-os v1.0.0 or later (with working pads):** copy `track3r-os-v1.4.1.ptf` into `Firmware/`, unzip the two zips at the card root, put the card in the unit, open Config, INFO and press `F8` (UPDATE).
- **From the official firmware, or when the pads are dead:** copy everything on the card to your computer; copy `track3r-os-v1.4.1.ptf` into `Firmware/` and rename the copy to `PolyendTracker_0.0.1.ptf` (it must be the only `.ptf` there); use the hidden reset button, as in Polyend's [emergency flashing page](https://polyend.ladesk.com/929798-How-do-I-perform-the-emergency-flashing-procedure); after the restart, open Config, INFO. BUILD ID should show `v1.4.1`. Then unzip the two zips at the card root.

The full steps are in the [installing guide](../manual/install.md).

## Tested

- The official 1.9.2 firmware file passes the device check, with only the PAD step left.
- Host tests of the update check: an image laid out like the official firmware is offered PAD, installs once padded, and a damaged flash configuration field is still refused.
- The full host suite, the emulator suite and the target build of this code; two clean builds of the tag give the same image.
