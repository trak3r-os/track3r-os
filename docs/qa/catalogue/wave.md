# Wave: feature catalogue

One row per user-visible function of the Wave screen (`docs/ui/ui-map.md` section 1; fixed table of `docs/specs/OS-FINALQA.md` section 1). IDs are never reused. The simulator scenario is `sim/scenarios/qa/qa_wave.txt`, its goldens are the `qa_wave/qa_wav_NNN` keys of `sim/goldens.txt`. These rows come from OS-UIFIX (UI only: no unit step); the Shift row is the same on the WAVE and the CHOP page. The rest of the screen's rows are added by the final batch.
