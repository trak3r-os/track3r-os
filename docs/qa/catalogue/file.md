# File: feature catalogue

One row per user-visible function of the File screen (`docs/ui/ui-map.md` section 1; fixed table of `docs/specs/OS-FINALQA.md` section 1). IDs are never reused. The simulator scenario is `sim/scenarios/qa/qa_file.txt`, its goldens are the `qa_file/qa_fil_NNN` keys of `sim/goldens.txt`. These rows come from OS-UIFIX (UI only: no unit step); the Shift row is Global's jumps over the list. OS-FILES part A adds the IMPORT page rows (003..011); OS-FILES part B the delete, recent and purge rows (030..044; 030, 031 and 043 were RENAME rows and are dropped: the IDs stay). The rest of the screen's rows are added by the final batch.
