# Instrument: feature catalogue

One row per user-visible function of the Instrument screen (`docs/ui/ui-map.md` section 1; fixed table of `docs/specs/OS-FINALQA.md` section 1). IDs are never reused. The simulator scenario is `sim/scenarios/qa/qa_instrument.txt`, its goldens are the `qa_instrument/qa_ins_NNN` keys of `sim/goldens.txt`. QA-INS-001 comes from OS-UIFIX (UI only: no unit step), QA-INS-002..004 from OS-IFX1 (the sound: no visible change, so no simulator snap); an instrument that a module draws shows the same Shift row. The rest of the screen's rows are added by the final batch.
