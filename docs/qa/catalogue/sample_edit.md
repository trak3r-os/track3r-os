# Sample edit: feature catalogue

One row per user-visible function of the Sample edit screen (`docs/ui/ui-map.md` section 1; fixed table of `docs/specs/OS-FINALQA.md` section 1). IDs are never reused. The simulator scenario is `sim/scenarios/qa/qa_sample_edit.txt`, its goldens are the `qa_sample_edit/qa_sed_NNN` keys of `sim/goldens.txt`. These rows come from OS-UIFIX (UI only: no unit step); every key of the row has a Shift binding. The rest of the screen's rows are added by the final batch.
