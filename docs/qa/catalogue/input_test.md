# Input test: feature catalogue

One row per user-visible function of the Input test screen (`docs/ui/ui-map.md` section 1; fixed table of `docs/specs/OS-FINALQA.md` section 1). IDs are never reused. It is a hidden diagnostic: no Navigator entry, no screen button, opened by a boot chord (QA-GLB-016), so a simulator scenario cannot reach it and there is no `qa_input_test.txt`; its pictures are the gallery's `inputtest_typical` (a few controls touched) and `inputtest_worst` (every counter at its widest). The row for its key row, QA-GLB-121 (F2 + F3 CLEAR, F4 + F5 EXIT), stays in `global.md` under its own ID and is not repeated here. Every control is read raw from the input path: nothing acts while the screen is up (`captures`).
