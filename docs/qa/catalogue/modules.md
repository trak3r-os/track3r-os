# Modules: feature catalogue

One row per user-visible function of the Modules screen (`docs/ui/ui-map.md` section 1; fixed table of `docs/specs/OS-FINALQA.md` section 1). IDs are never reused. The simulator scenario is `sim/scenarios/qa/qa_modules.txt`, its goldens are the `qa_modules/qa_mod_NNN` keys of `sim/goldens.txt`. These rows come from OS-UIFIX (UI only: no unit step); the screen is reached from the Navigator only (the scenario opens it with `nav.screen 12`). The rest of the screen's rows are added by the final batch. QA-MOD-002..008 are the Tap Calc app (OS-TAPCALC), QA-MOD-009..016 the app host API v2 slice H1 of ADR 0014 (the first-launch confirm and the MIDI Monitor app), QA-MOD-017..023 slice H2a (ABI 1.4: the audio tap and the Loudness VU app); apps on an SD card were not run by the simulator until OS-APPUX S0, so their rows have a host test (`o3m_<app>_test`, `module_host_api_test`) and a unit step in `qa_modules.json`. **Since OS-APPUX S0 the simulator carries the shipped apps** (scenario command `apps on`, `sim/include/o3os/sim/sim_apps.h`: the host objects of the per-app tests): a row whose Sim cell still says an SD app is not in the simulator predates it and is not scripted yet; the app-page rows with a snap in `qa_modules.txt` are QA-MOD-009, 010, 024, 117 and 120..122.
