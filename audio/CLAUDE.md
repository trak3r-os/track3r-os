# audio/ — engine, graph, voices, kernels (the render path)

- Owns the block-based render (`Engine` -> `Graph::render()`), sampler/Amiga/module voices, send effects, meters, taps. Everything the render calls: no allocation, no SD I/O, no blocking, no virtual call, no libm, no flash call on the per-block path, no `double`, bounded loops. May include `core`, `usb`, `hal`, `module` only (not `model`, `app`, `ui`, `formats`; `check_layers.py`).
- Entry points:
  - `include/o3os/audio/engine.h`: one block in order (input, drain, render, strips, buses, master, convert, taps)
  - `include/o3os/audio/graph.h` + `graph_params.h`: fixed graph; its ParamIds
  - `include/o3os/audio/voices.h`: sampler voice pool (one voice per track, oldest stolen)
  - `include/o3os/audio/kernels.h` + `simd.h`: Q15 sample kernels with Cortex-M4 DSP instructions
  - `include/o3os/audio/pipeline.h`, `slot_ring.h`: the DMA-boundary ISR and render-line entry points; `hot.h`: `O3OS_AUDIO_HOT` places code in SRAM_L
  - `include/o3os/audio/loop_player.h`: the looper's loop (OS-LOOPER L1): clocked by Step events, mixed into the TX block after the taps, in flash (`O3OS_AUDIO_COLD`); overdub session (L2c: command word + acknowledged sequence, copy-on-write undo, bounded restore) in `src/loop_session.cpp`, kernels in `loop_overdub.h` / `src/loop_player.cpp`; tests `tests/audio_loop_test.cpp`, `tests/audio_loop_overdub_test.cpp`
  - `Graph::quiet_tracks()` -> `Engine::play_block` -> `VoicePool::set_gate` (OS-ODD11): a voice on an inaudible strip skips its tremolo, filter and shaper and is not fed; the gate is empty in an export (`voices.h` GATE); slice 2: a plain gated voice (one shot or forward loop) does not run its sample loop either, `VoicePool::gated_span` advances it in closed form (`advance`, flash; `diag voices` shows the `advanced` span count); tests `tests/audio_gate_test.cpp`, `tests/audio_advance_test.cpp`
  - OS-PERFFX P0 (docs/specs/OS-PERFFX.md), the Perform layer in the voices and strips: `Engine::dispatch` hands `VoicePool::fx_event(track, const SeqEvent&)` the whole ModSet / ModEnd (flash); `layer_event` keeps the layer's value of Overdrive and Bit depth (`perf_`, `voices.h` PERFORMANCE LAYER) and `Strip::perf_gain` / `perf_pan` are the strips' (P2: `TrackerFx::event` -> `Graph::set_perf_gain` / `set_perf_pan`, composed in `recompute_strip`: VOLUME only cuts, PANNING adds to the pan in force). P3: the Delay send and Reverb send groups (`TrackerFx::event` -> `Graph::set_perf_send` for the layer's DELAY / REVERB offset, `set_step_send` for the step FX 30 / 32 held) are composed in `recompute_strip` with the instrument's sends, so every `set_voice_sends` caller has them (`Strip::perf_send_a/b`, `step_send_a/b`, bytes; the instrument's sends are bytes now too: `sizeof(Strip)` unchanged). FxReset and Stopped leave the layer's fields (FxReset ends the step FX's, `TrackerFx::reset`); `Engine::offline_enter` / `offline_leave` put away, clear and restore them (`perf_save` / `perf_clear` / `perf_restore`, the performance filter included). New state goes in SRAM_U, never SRAM_L (`.ramfunc_l` net 0 B per slice); tests `tests/audio_perform_test.cpp` (also `qemu_audio_perform`), `audio_gate_test.cpp`, `audio_advance_test.cpp` OS-PERFFX P1: `VoicePool::shape_set` (flash) takes the layer's Overdrive / Bit depth value over the step FX's and the instrument's (BITDEPTH value = the shift, 16 - bits); the sounding voice follows through `ifx_event`; tests `audio_voices_test.cpp` (the curves of the layer), `audio_perform_test.cpp` (FxReset, Stopped, the export), `audio_gate_test.cpp`, `audio_advance_test.cpp`. P5: the layer's TUNE (`kModGroupTune`, third `PerfSlots` slot, -48..48) is the base of the pitch offset: every writer of `Voice::slide_q16` / `slide_tgt` in `voices.cpp` keeps `tune_base_q16(track)` (flash) as its zero (note start, Slide FX, Glide, tracker FX, a live change adds the difference); the pitch is still made by `repitch` in `mod_block`; tests `audio_voices_test.cpp` (P5), `audio_perform_test.cpp`, `seq_perform_send_test.cpp`.
  - OS-PERFFX P7 (SMP POS / SMP END at the note start, `smp_window` / `smp_frame` in flash, docs/specs/OS-PERFFX.md section 10): `note_on` grew +48 B of `.ramfunc_l` (headroom 364 -> 316 B), an exception to the net-zero rule (D1), accepted by the orchestrator while the maintainer is away and recorded for the maintainer; follow-up done by OS-PERF-CPU3 slice 1: the `note_on` tail (envelope or attack ramp, `dk`, `gated_`, `age`, `playing`, note counter) now runs at the end of `mods_start` (flash, takes the voice index), `.ramfunc_l` -144 B (27,472 -> 27,328 B); test `tests/audio_noteon_state_test.cpp` (whole voice state hashed after random notes), bench rows `note_on_table`. `Voice::gstart` of a non-granular voice (the window start, set in flash by `mods_start`) is where `tracker_retrigger` restarts.
  - OS-PERF-REVERSE (P8, PLAYBACK = `Voice::mode` 4, `kModeReverse`; docs/specs/OS-PERFFX.md section 10.5): `run<true, true>` (`run_dir`) got a `rev` flag, an entry test and the stop below the window's first frame: `.ramfunc_l` +52 B (27,332 -> 27,384 B, headroom 316 -> 264 B), a second exception to the net-zero rule (D1), the first being P7; `mods_start` (flash) turns a note of a track with `perf_rev_` / `step_rev_` backward, `note_on` is untouched. A backward voice has `mode != 0`: no closed-form advance when gated (OS-PERF-CPU2 D4); its fast path is the next bullet.
  - OS-PERF-CPU2 A1 (docs/specs/OS-PERF-CPU2.md; the backward fast path): `run<true, true>` (`run_dir`: reversed notes and backward / ping-pong instrument loops) walks the first k = floor((idx0 - loop_start) / (floor(inc) + 1)) samples of a call through `fast_steady` / `fast_ramp` with the increment negated in `Voice::inc` for the call (put back at once; nothing reads it in between), entry guard `bwd`, signed `idx0 >= loop_start` (a live loop edit can raise `loop_start` above the phase) and `idx0 + 2 <= end`; the checked loop takes the rest (the sample at `end - 1`, turns, the stop). Bit-identical, voice state included; the forward path and `fast_steady` / `fast_ramp` are unchanged (98 and 120 B). `.ramfunc_l` +92 B (27,380 -> 27,472 B, headroom 268 -> 176 B): a fourth exception to the net-zero rule (D1, up to +96 B; more stops for a decision). Tests `tests/audio_voices_dir_test.cpp` (`friend struct VoiceRunTest`: a randomized differential test against a scalar copy of the old checked loop, plus 21 hashes captured before the change; also `qemu_audio_voices`), bench rows `tests/bench/audio_bench.cpp` (12 reversed voices) and `diag bench voice_rev`; QA-PRF-170..172.
  - OS-PERF-CPU2 P1 (tried and dropped): `Graph::set_voice_pan` already returns when the strip's `pan_offset` equals the new pan (graph.cpp:312), so skipping the call in `Engine::apply_pan_mods` saved nothing measurable; the code was reverted. A held LFO re-sends its pan every block and so overrides the other writers of `pan_offset` (the Panning FX, a pan slide and its end, a live instrument-pan edit): any future skip must compare with the strip's own value, never a cached one. Tests `audio_perflfo_test.cpp` (`pan sent only when it changed`, nine scenes, also on the target) pin that behaviour; bench rows `diag bench voice_pan` and `audio_bench` (LFO destinations through the engine).
  - OS-PERF-LFO-STEP (docs/specs/OS-PERF-LFO-STEP.md; the step FX 23, 24, 33 and 36 act): `VoicePool::step_lfo_[4][16]` (SRAM_U, rows VOL, PAN, TUNE, POS; rate index + 1) is set by `layer_event` only for the group's own FX (`kFxLfoVolume` ... `kFxLfoPosition`, events.h; any other ModSet or a ModEnd clears it), read by `perf_index` (the layer's offset when held and not 0, else the step's absolute index, VOL + 5) and `perf_lfo_held` (mods_start), ended by FxReset inside `lfo_set_impl`'s all-tracks branch (Stopped leaves it) and put away / back by `perf_clear` / `perf_save` / `perf_restore` (`PerfSave::step_lfo`). All in flash, no new per-block code; a step FX 36 on a plain sample starts no modulator. Last writer wins against the Panning FX 31 (D4). Tests `audio_perflfo_test.cpp` (`step lfo:`, `friend struct LfoStepTest`), `seq_pfx_test.cpp`, `audio_model_ids_test.cpp`; QA-PRF-180..189, HIL `qa_lfostep.json`.
  - OS-BUG-MODDRIVE (docs/specs/OS-BUG-MODDRIVE.md; Overdrive / Bit depth on module instruments): `Engine::play_block`, after the modules' `end_block`, tests `voices_->shape_mask()` (the tracks holding FX 38 / 39 or the layer's OVERDRV / BITDEPTH; zero: no call) and calls `Engine::shape_modules` (flash) which shapes each sounding module track's block in place through `ModuleVoices::feed_mut` with `VoicePool::shape_track` (the rule of `shape_set`, neutral instrument values) and `VoicePool::shape_pcm` (the curve `shape_span` also runs). EXCEPTIONS to "no flash call on the per-block path" (also in `hot.h`): `shape_modules`, `shape_track` and `shape_pcm`, once a block while any track holds either FX, plus one `shape_track` / `shape_pcm` per shaped module track. `.ramfunc_l`: the gate test and one call in `play_block` only (a third exception to the net-zero rule, after P7 and P8; the delta is in the commit). The values in force at the block's end act on the whole block (up to one block early); the cost lands in the governor's `base`. Tests `tests/module_voices_test.cpp` (`module drive:`); HIL `qa_cpu_moddrive.json`.
  - OS-STEREO (c) (docs/specs/OS-STEREO.md "Slice (c) as built"; `voices.h` STEREO VOICES): a note of a stereo instrument (`SampleDesc::st_off`, set by `app::make_sample_desc` from the flag and the bank's S) makes S beside M: `VoicePool::st_start` (flash, end of `mods_start`) decides per note and holds one of 4 side blocks (`sblocks_`, `st_`; `Voice::st` is the block index + 1 and the on bit); `run_st` / `fast_st` / `st_tail` (flash) are `run<Ramp, false, true>` with S and S's own residual; `render_seg` has the one branch (`v.st != 0`), `render`, `find`, `allocate`, `end_block` count a voice that holds a block as live; `end_block_st` (flash, only while a block is held) hands the blocks to `side_mask()` / `feed_side()`, `Engine::feed_sides` (flash) to `Graph::feed_side`, and `run_tracks` calls `kernel::gain_pan_st` (flash; L += S, R -= S through the strip's level ramp and pan gains) per stereo track. M is bit-identical to the mono voice (tests `audio_stereo_test.cpp`: S equals the mono render of the S wave, also `qemu_audio_stereo`); a gated voice, an effect of S5 turned on, a module or Amiga feed drop S. New state in SRAM_U at the end of `VoicePool` and `Graph`; flash exceptions are in `hot.h`.
  - OS-INSFX S1 (docs/specs/OS-INSFX.md; effect modules as per-track inserts, console only): `include/o3os/audio/insert_host.h` + `src/insert_host.cpp` (all flash, `O3OS_AUDIO_COLD`): `InsertHost` owns 4 instances, `run` is the Graph's `InsertFn` (the float / Q15 adapter, `module_q15.h`'s module rule, a one-block dry / wet ramp in a transition, an idle skip), `begin_block` (called by `Engine::block_end`, the old `block_done` call site, and at the start of each export block) retires the ramping-out slots, runs both nets and applies the 8-byte command ring; `ParamKind::Insert` reaches `apply_param` through `Engine::param_route` (the graph's param hook, no new case in `Graph::apply`); a 16-bit generation per binding (carried in `ParamChange::ramp_samples`) drops a stale change after a record was reused. The Graph's slots are written only by the render context. Insert cycles stay in the governor's `base` (the host does not call `Governor::account`); the aggregate net and `admit()` judge the same input, `others_pub_` = max(slow mean (1/256), fast mean (1/32) less 5 %) of `Governor::last_total()` less the inserts' own cycles (so the instrument-module voices count; the note admission is unchanged), and a first bind of a never measured module counts the candidate as 0 (the nets judge it after; an un-bypass keeps the cold 10 %) (running averages for the first blocks, seed at most the threshold, kept across an export), not the base's peak: a busy project that plays (mean 86 %, peaks 117 %) keeps a 1.3 % insert and a 15 % bind is refused, and a light render that turns heavy is acted on in about 35 blocks. Un-bypass and the start of an export (`prepare_export`) are a `shutdown` + `init`. Platform wiring `platform/mk66/src/app_main.cpp` (`g_insert_host`, `insert_bind`...), console `ins` (`list`, `bind`, `unbind`, `bypass`), `diag bench insert` (rows `insert_effect`, `insert_ramp`, `insert`; the adapter is `insert` minus `insert_effect`; `InsertBinder` is S3); test `tests/audio_insert_test.cpp` (identity with no insert, counting allocator, command phases, S ramp); QA-GLB-161..166, HIL `qa_inserts.json`. New state in SRAM_U, never SRAM_L (`.ramfunc_l` net 0 B; D8): a console-bound insert is not saved until S3. OS-INSFX S2 (effect tails): `Graph::Insert::tail` (a byte in the Insert's padding; `sizeof(Strip)` 216) is set by `InsertHost::run` while `render()` returns 1 (ends at 0, at 2 s of exact zero Q15 output with a silent source, or at 10 s of silent input; fold: a delay's echo survives gaps); `run_tracks`' `!make` branch reads it and feeds the strip the Graph's `zero_` block through the inserts, sends and fader, so a strip that only rings costs what a live one does and an idle one costs the idle figure; `.ramfunc_l` +24 B (27,548 -> 27,572 B, headroom 176 -> 152 B; the cap was +32 B, D8), SRAM_U +16 B; tests `audio_insert_test.cpp` (`tail:`), QA-GLB-167.
  - OS-INSFX S3b (inserts saved with the project): the binder is `app::ModuleBinder`'s third phase (`app/include/o3os/app/module_binder.h`, `bind_insert_next`; `begin(..., &g_insert_host)` from `begin_modules` in `platform/mk66/src/app_main.cpp`): after the instruments it binds the effect modules the `INSX` records name, `force` (unadmitted), main loop, one record a step. Test `tests/audio_insert_binder_test.cpp`.
  - `include/o3os/audio/events.h`: sequencer -> voices contract; `module_voices.h`, `module_governor.h`: SD modules
- Parameters reach the render only as `ParamChange` through the ring, drained in the graph's pass, after the block's voices have rendered (bounded per block). Events (`events.h`) have a stable 12-byte layout: add a kind at the end of its group, never change an existing kind's fields.
- Add a kernel: a scalar `*_ref` as the specification plus the production variant, bit-identical, tested in `tests/audio_kernels_test.cpp`. Mark per-block hot code `O3OS_AUDIO_HOT`. A graph parameter shared with the model is checked by `tests/audio_model_ids_test.cpp`.
- Main-loop guard (OS-MAINGUARD, ADR 0013 amendment 7): `Pipeline::main_pass()` is called once per main-loop pass; without it the render sheds blocks after N (default 64, `Pipeline::set_starve_blocks`, console `guard n <1..255>`) stale over-budget renders. A new main loop (or a test that plays a real engine under load) must call it and arm `starve_guard`.
