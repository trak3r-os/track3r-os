# audio/ — engine, graph, voices, kernels (the render path)

- Owns the block-based render (`Engine` -> `Graph::render()`), sampler/Amiga/module voices, send effects, meters, taps. Everything the render calls: no allocation, no SD I/O, no blocking, no virtual call, no libm, no flash call on the per-block path, no `double`, bounded loops. May include `core`, `usb`, `hal`, `module` only (not `model`, `app`, `ui`, `formats`; `check_layers.py`).
- Entry points:
  - `include/o3os/audio/engine.h`: one block in order (input, drain, render, strips, buses, master, convert, taps)
  - `include/o3os/audio/graph.h` + `graph_params.h`: fixed graph; its ParamIds
  - `include/o3os/audio/voices.h`: sampler voice pool (one voice per track, oldest stolen)
  - `include/o3os/audio/kernels.h` + `simd.h`: Q15 sample kernels with Cortex-M4 DSP instructions
  - `include/o3os/audio/pipeline.h`, `slot_ring.h`: the DMA-boundary ISR and render-line entry points; `hot.h`: `O3OS_AUDIO_HOT` places code in SRAM_L
  - `include/o3os/audio/loop_player.h`: the looper's loop (OS-LOOPER L1): clocked by Step events, mixed into the TX block after the taps, in flash (`O3OS_AUDIO_COLD`); overdub session (L2c: command word + acknowledged sequence, copy-on-write undo, bounded restore) in `src/loop_session.cpp`, kernels in `loop_overdub.h` / `src/loop_player.cpp`; tests `tests/audio_loop_test.cpp`, `tests/audio_loop_overdub_test.cpp`
  - `Graph::quiet_tracks()` -> `Engine::play_block` -> `VoicePool::set_gate` (OS-ODD11): a voice on an inaudible strip skips its tremolo, filter and shaper and is not fed; the gate is empty in an export (`voices.h` GATE); slice 2: a plain gated voice (one shot or forward loop) does not run its sample loop either, `VoicePool::gated_span` advances it in closed form (`advance`, flash; `diag voices` shows the `advanced` span count); tests `tests/audio_gate_test.cpp`, `tests/audio_advance_test.cpp`
  - OS-PERFFX P0 (docs/specs/OS-PERFFX.md), the Perform layer in the voices and strips: `Engine::dispatch` hands `VoicePool::fx_event(track, const SeqEvent&)` the whole ModSet / ModEnd (flash); `layer_event` keeps the layer's value of Overdrive and Bit depth (`perf_`, `voices.h` PERFORMANCE LAYER) and `Strip::perf_gain` / `perf_pan` are the strips' (P2: `TrackerFx::event` -> `Graph::set_perf_gain` / `set_perf_pan`, composed in `recompute_strip`: VOLUME only cuts, PANNING adds to the pan in force). P3: the Delay send and Reverb send groups (`TrackerFx::event` -> `Graph::set_perf_send` for the layer's DELAY / REVERB offset, `set_step_send` for the step FX 30 / 32 held) are composed in `recompute_strip` with the instrument's sends, so every `set_voice_sends` caller has them (`Strip::perf_send_a/b`, `step_send_a/b`, bytes; the instrument's sends are bytes now too: `sizeof(Strip)` unchanged). FxReset and Stopped leave the layer's fields (FxReset ends the step FX's, `TrackerFx::reset`); `Engine::offline_enter` / `offline_leave` put away, clear and restore them (`perf_save` / `perf_clear` / `perf_restore`, the performance filter included). New state goes in SRAM_U, never SRAM_L (`.ramfunc_l` net 0 B per slice); tests `tests/audio_perform_test.cpp` (also `qemu_audio_perform`), `audio_gate_test.cpp`, `audio_advance_test.cpp` OS-PERFFX P1: `VoicePool::shape_set` (flash) takes the layer's Overdrive / Bit depth value over the step FX's and the instrument's (BITDEPTH value = the shift, 16 - bits); the sounding voice follows through `ifx_event`; tests `audio_voices_test.cpp` (the curves of the layer), `audio_perform_test.cpp` (FxReset, Stopped, the export), `audio_gate_test.cpp`, `audio_advance_test.cpp`. P5: the layer's TUNE (`kModGroupTune`, third `PerfSlots` slot, -48..48) is the base of the pitch offset: every writer of `Voice::slide_q16` / `slide_tgt` in `voices.cpp` keeps `tune_base_q16(track)` (flash) as its zero (note start, Slide FX, Glide, tracker FX, a live change adds the difference); the pitch is still made by `repitch` in `mod_block`; tests `audio_voices_test.cpp` (P5), `audio_perform_test.cpp`, `seq_perform_send_test.cpp`.
  - OS-PERFFX P7 (SMP POS / SMP END at the note start, `smp_window` / `smp_frame` in flash, docs/specs/OS-PERFFX.md section 10): `note_on` grew +48 B of `.ramfunc_l` (headroom 364 -> 316 B), an exception to the net-zero rule (D1), accepted by the orchestrator while the maintainer is away and recorded for the maintainer; follow-up: move the `note_on` tail to flash. `Voice::gstart` of a non-granular voice (the window start, set in flash by `mods_start`) is where `tracker_retrigger` restarts.
  - OS-PERF-REVERSE (P8, PLAYBACK = `Voice::mode` 4, `kModeReverse`; docs/specs/OS-PERFFX.md section 10.5): `run<true, true>` (`run_dir`) got a `rev` flag, an entry test and the stop below the window's first frame: `.ramfunc_l` +52 B (27,332 -> 27,384 B, headroom 316 -> 264 B), a second exception to the net-zero rule (D1), the first being P7; `mods_start` (flash) turns a note of a track with `perf_rev_` / `step_rev_` backward, `note_on` is untouched. A backward voice has `mode != 0`: no fast path, no closed-form advance when gated.
  - OS-BUG-MODDRIVE (docs/specs/OS-BUG-MODDRIVE.md; Overdrive / Bit depth on module instruments): `Engine::play_block`, after the modules' `end_block`, tests `voices_->shape_mask()` (the tracks holding FX 38 / 39 or the layer's OVERDRV / BITDEPTH; zero: no call) and calls `Engine::shape_modules` (flash) which shapes each sounding module track's block in place through `ModuleVoices::feed_mut` with `VoicePool::shape_track` (the rule of `shape_set`, neutral instrument values) and `VoicePool::shape_pcm` (the curve `shape_span` also runs). EXCEPTIONS to "no flash call on the per-block path" (also in `hot.h`): `shape_modules`, `shape_track` and `shape_pcm`, once a block while any track holds either FX, plus one `shape_track` / `shape_pcm` per shaped module track. `.ramfunc_l`: the gate test and one call in `play_block` only (a third exception to the net-zero rule, after P7 and P8; the delta is in the commit). The values in force at the block's end act on the whole block (up to one block early); the cost lands in the governor's `base`. Tests `tests/module_voices_test.cpp` (`module drive:`); HIL `qa_cpu_moddrive.json`.
  - `include/o3os/audio/events.h`: sequencer -> voices contract; `module_voices.h`, `module_governor.h`: SD modules
- Parameters reach the render only as `ParamChange` through the ring, drained in the graph's pass, after the block's voices have rendered (bounded per block). Events (`events.h`) have a stable 12-byte layout: add a kind at the end of its group, never change an existing kind's fields.
- Add a kernel: a scalar `*_ref` as the specification plus the production variant, bit-identical, tested in `tests/audio_kernels_test.cpp`. Mark per-block hot code `O3OS_AUDIO_HOT`. A graph parameter shared with the model is checked by `tests/audio_model_ids_test.cpp`.
- Main-loop guard (OS-MAINGUARD, ADR 0013 amendment 7): `Pipeline::main_pass()` is called once per main-loop pass; without it the render sheds blocks after N (default 64, `Pipeline::set_starve_blocks`, console `guard n <1..255>`) stale over-budget renders. A new main loop (or a test that plays a real engine under load) must call it and arm `starve_guard`.
- Cost: measure on the unit before merge (`docs/architecture/cpu-budget.md`, skills `rt-optimize`, `dsp-port`). `tests/bench/audio_bench.cpp` (ctest `audio_bench_smoke` is a smoke run only). Hardware steps: `platform/mk66/tools/hil/{cpu_play,stress_voices,limiter_*}.json`.
- Tests: `tests/{audio_*,tb303_*,amiga_*}_test.cpp`, `paula_oracle_test.cpp`. Scoped: `ctest --test-dir build-os-host -R unit_audio --output-on-failure` (or `-L audio`); `O3OS_CI_SCOPE=changed tools/ci.sh host` maps `audio/` to labels `audio seq`. `qemu_audio*` run under `tools/ci.sh qemu`.
- Docs: `docs/specs/OS-005-audio-engine.md`, ADR 0013 (D1 execution model, D2 sample format, D3 voices, D4 graph, D5 sequencer, D6 parameters, D7 memory placement). QA rows go in `docs/qa/catalogue/<screen>.md` (format in `app/CLAUDE.md`).
